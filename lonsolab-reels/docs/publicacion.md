# Guía de publicación — reels de Lonso Lab

Archivos finales: `studio/out/<reel>.final.mp4` (1080×1920, 30 fps, H.264 + AAC, −14 LUFS). Se regeneran con
`npx remotion render src/reels/<reel>/index.tsx <Id> out/<reel>.mp4` + `python3 ../tools/master.py out/<reel>.mp4`
(antes, `python3 tools/cut_music.py` para crear las bases de música).

Recomendaciones generales:
- Subí el archivo tal cual (no lo recortes en la app). Elegí la portada desde el momento indicado o subí una aparte.
- Música: son pistas de Suno generadas con tu plan pago; en Instagram queda como "audio original".
- Publicá uno cada 2–3 días alternando fondos (papel / cobalto / tinta) para que la grilla quede prolija.
- Si activás una respuesta automática por mensaje, podés cambiar el CTA del texto a "Escribí AUDITORÍA por mensaje".
