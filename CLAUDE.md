# Repo nextro1

- Raíz: la web de **Nextro** (React + Vite + Tailwind), la marca anterior del usuario.
- `lonsolab-reels/`: el proyecto activo. Son reels de Instagram para **Lonso Lab**, hechos con Remotion.
  **Leé `lonsolab-reels/HANDOFF.md` antes de tocar nada**: explica el estado, las decisiones pendientes y cómo abrir
  Remotion Studio (`cd lonsolab-reels/studio && npm install && npm run dev`, vista previa en http://localhost:3000).
- El usuario habla en español rioplatense; los videos van en voseo.
